# ami****yet.com

A sobriety testing tool for drug harm-reduction in legal (e.g. clinical) settings.

In other words — answering the age-old question:  
“Did the _ kick in yet?”

## Contributing

### Basic Idea

Fork the repo and:

1. Create a new directory using `kebab-case`.
2. Inside it, create an `index.html` file containing your test.
3. Hack together or vibe-code something that feels experientially different when high versus sober.
4. Add your link to the main page navigation.
5. Submit a pull request.

### Rules & Guidelines

1. **No hotlinking.** Each directory should work offline without external dependencies.  
2. **Avoid page margins** with immersive content.  
3. **Have fun.** Haha, what a goofy rule, derp.
